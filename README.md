## Additional Information
I believe I have set a lof of this project up so that someone else could fork this project and apply thier own information.

### Where to Apply Changes
Changing different values in the TypeScript files located in ./src/data/

- site-constants.ts
    - Can change various site constants like site name and description.
- navigation.ts
    - Change the navigation tabs in the navbar.
- resume-constants.ts
    - The most tedious by far. Update resume information here.
- contact-constants.ts
    - Can change to tailor to your email and socials.

I have also added template for the project and journal entries as well as placeholder images.
